# 🌍 Solo Adventure Travel Guide
https://varshinimv17.github.io/solo-adventure-travel-guide/
## 📖 Overview

Solo Adventure Travel Guide is an AI-powered travel planning platform designed for solo travelers and adventure enthusiasts. The website helps users discover exciting destinations, create personalized itineraries, find budget-friendly accommodations, explore local attractions, receive safety tips, and connect with like-minded travelers.

The platform provides travel recommendations, budget planning, destination information, adventure activity suggestions, and AI-assisted travel guidance to make solo journeys safer, smarter, and more enjoyable.

* 🌍 AI-Powered Travel Recommendations

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/solo-adventure-travel-guide.git
```

### Open Project Folder

```bash
cd solo-adventure-travel-guide
```

### Install Dependencies

```bash
npm install
```

### Run Application

```bash
node server.js
```

### Open Browser

```text
http://localhost:3000
```

---

## 🧠 How It Works

1. User enters a destination and travel duration.
2. System generates a personalized itinerary.
3. User receives budget estimates and travel suggestions.
4. Safety recommendations are displayed.
5. MindPal AI provides travel assistance and recommendations.
